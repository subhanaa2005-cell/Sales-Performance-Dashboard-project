# Sales-Performance-Dashboard-project
📊 Sales Performance Dashboard
This project presents a Sales Performance Dashboard built using Power BI, designed to visualize and analyze multi‑year sales data. It provides a clear overview of key business metrics such as total revenue (€126.01M), gross profit (€86.89M), and profit margins (~69%), along with detailed insights into product and category performance.

🔍 Key Features
Interactive filters for year and category selection (2014–2017).

Visuals include:

Pie chart showing unit distribution by subcategory.

Line chart tracking monthly revenue trends.

Bar charts comparing yearly and product‑wise revenues.

Stacked column chart illustrating revenue breakdown by category and year.

Comprehensive product table with revenue, profit, margin, and units sold.

Clean purple‑themed design for professional presentation.

💡 Insights
“Extra” category leads with 45.52% of total units sold.

Magnum, Quad, and Carlota are top‑performing products.

Consistent revenue growth observed from 2014 to 2017.

Balanced discount strategy maintaining strong profit margins.

🛠️ Tools Used
Microsoft Power BI for data visualization

Excel / CSV for data preprocessing

DAX for calculated measures and KPIs

📁 Purpose
To demonstrate how Power BI can transform raw sales data into actionable insights for business decision‑making and performance tracking.
